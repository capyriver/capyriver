# CapyRiver

I build practical AI software for everyday devices, with a focus on local inference, useful developer tools, and honest engineering.

**Focus:** local AI · Windows and Android apps · model integration · Python · C#/.NET · MCP

## Projects

- **[CapyRiver](https://capyriver.pages.dev/)** — local AI for Android and PC. [Downloads](https://github.com/capyriver/CapyRiver-Downloads/releases)
- **[NORA — CapyRiver Edition](https://github.com/capyriver/NORA-CapyRiver)** — a Windows workspace for local AI models, chats, files, projects, and optional MCP tools.
- **[Soup](https://github.com/MakazhanAlpamys/Soup)** — open-source contributions to training, benchmarking, and Hugging Face Spaces workflows.

## How I work

I try to make model provenance, hardware requirements, and limitations clear. I value reproducible checks, measured results, and tools that are understandable to the people using them.
